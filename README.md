# Vercel On-Demand - Portafolio Auto Responder

Este es 100% Vercel y solo trabaja cuando TU quieres.

## Deploy a Vercel

1. Ve a vercel.com/new
2. Arrastra la carpeta o el index.html + vercel.json
3. Deploy
4. Te da un link https://tu-proyecto.vercel.app

## Uso

1. Abre tu link de Vercel
2. Pega tu token EAA... del Usuario del Sistema (el que te da 8 páginas)
3. Activa con toggle tus 8 páginas: Ives Hernandez 01-08, Ives Show, etc.
4. Dale a "Escanear TODO lo pendiente" - te dice cuántos comentarios nunca respondiste
5. Dale a "Responder TODO lo pendiente lento anti-spam"

Solo responde mientras la pestaña está abierta y le diste a Activar.
Cuando le das a Pausar o cierras Vercel, deja de responder.

Anti-spam: 90-180 segundos entre respuestas, no repite mensaje seguido.
